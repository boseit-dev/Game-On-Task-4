# Crystal Rush — Game On Task 4

My Year 9 JavaScript game project.

## Game idea
Crystal Rush is a two-player game where players collect crystals, avoid obstacles, and complete three levels.

## Planned features
- Three levels with different obstacles and backgrounds
- Two characters: Player 1 (WASD) and Player 2 (arrow keys)
- Scores and three lives for each player
- Sounds and simple background music
- Start, game-over, and victory screens
- Full browser-window game

## How to play (when the game is finished)
Open `index.html` in a browser. Press **Enter** to start. Player 1 uses **WASD**. Player 2 uses the **arrow keys**. Press **M** to mute or unmute sounds.
